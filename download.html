Warning — Unsafe Mode

This mod requires an intermediate level of English and is not recommended for children under 14!

This mod can interact with your computer but is not a virus. By default these functions are disabled, but you can enable them with the /unsafemode command. If you enabled it and changed your mind, you can reset it by typing the /safemode command.

If unsafe mode is enabled, the following things will happen:

  • Shut down the computer, open a Windows cmd / Linux terminal and use a non-malicious command
  • Change the desktop wallpaper
  • Open files
  • Show your IP address and Windows/Linux username in the chat
  • Open the camera
  • Ban you from a single-player world, or delete a single/multiplayer world
  • Create fake error windows
