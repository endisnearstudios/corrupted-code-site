Breakable · Protected Marker World-Structure Blocks

control_block

A protected marker the maze-carving logic never removes.

Unlike the other structural blocks around it, control_block is only iron-block strength, meaning it can actually be broken. Functionally, though, it is a protected "anchor point": the Integrated Void's corridor-carving logic never deletes it, no matter how the surrounding corridors and rooms get carved out, which is what keeps the maze's key room structures stable.
